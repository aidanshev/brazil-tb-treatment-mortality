# Code Availability

Suggested manuscript statement while the executable archive remains unrecovered:

> A public results/provenance repository is available at https://github.com/aidanshev/brazil-tb-treatment-mortality. It contains the locked 2024 aggregate performance metrics, paired uncertainty results, endpoint and validation boundaries, data-source documentation, and publication-safety checks. The original complete model-development and validation package has not yet been recovered into the public repository; this deposit therefore must not be described as the complete executable code archive. Raw patient-level SINAN records are not redistributed.

A manuscript claiming complete code availability should be finalized only after the original executable package is recovered, validated from a fresh extraction, materialized in publication-safe form, and archived as an immutable release with a DOI.
